## 第一部分：制作 PE 启动盘

### 方案选择

将 U 盘做成 PE 启动盘有多种方案，本指南采用 **Ventoy + ISO 镜像** 的方式，优势在于：

- U 盘无需反复格式化，直接拷贝/删除 ISO 即可增删启动项
- 支持同时存放多个 ISO（PE、Windows 安装镜像、Linux 等）
- 兼容 UEFI 和 Legacy 两种启动模式

### 所需工具

| 工具 | 大小 | 用途 |
|------|------|------|
| Ventoy (v1.0.99) | ~20 MB | U 盘引导管理器，自动识别 ISO |
| WinPEEnhanced.iso | 391 MB | 精简版 PE 维护环境 |
| Win10_22H2_Pro_x64.iso | 5.72 GB | Windows 10 专业版安装镜像 |
| FirPE (V2.1.1) | ~1.2 GB | 全功能 PE，内置检测工具 |

### 制作步骤

1. **备份 U 盘数据** — Ventoy 安装过程会格式化 U 盘，所有数据将清空。建议确认 U 盘容量 8GB 以上。
2. **安装 Ventoy** — 运行 Ventoy2Disk，选择 U 盘，分区格式选 exFAT（支持大文件），点击"安装"。等待提示安装成功后关闭窗口。
3. **复制 PE 镜像** — 将 `WinPEEnhanced.iso` 复制到 U 盘根目录。Ventoy 会自动识别根目录下所有 ISO 文件。
4. **复制 Windows 安装镜像** — 将 `Win10_22H2_Pro_x64.iso` 同样复制到 U 盘根目录。
5. **（可选）添加 FirPE** — 运行 FirPE 安装程序，点击"生成ISO"按钮，将生成的 ISO 也复制到 U 盘根目录。FirPE 内置 CPU-Z、CrystalDiskInfo、DiskGenius、HWMonitor 等工具，功能更全面。

> **提示：** Ventoy 安装完成后，U 盘就是普通的 exFAT 分区，直接像普通 U 盘一样拷贝/删除 ISO 文件即可，不需要重新安装 Ventoy。启动时 Ventoy 菜单会自动列出所有 ISO。

### 最终 U 盘内容

| 文件 | 大小 | 用途 |
|------|------|------|
| WinPEEnhanced.iso | 391 MB | 精简 PE 维护环境（可删除，FirPE 可替代） |
| Win10_22H2_Pro_x64.iso | 5.72 GB | Windows 10 专业版安装 |
| FirPE.iso | ~1.2 GB | 全功能 PE（内置检测工具） |

### 启动设置

制作完成后，重启电脑时按以下快捷键调出启动菜单：

| 品牌 | 快捷键 |
|------|--------|
| 联想 | F12 |
| 戴尔 | F12 |
| 惠普 | F9 |
| 华硕 | F8 / Esc |
| 微星 | F11 |
| 技嘉 | F12 |

在启动菜单中选择 U 盘，进入 Ventoy 菜单后选择需要的 ISO 即可。

## 第二部分：在无硬盘电脑上使用 PE 盘

PE 盘可以在任何能从 USB 启动的电脑上使用，**不需要电脑有硬盘**。PE 系统启动后完全运行在内存（RAM）中，不依赖本地硬盘。

### 使用流程

1. 将 PE 盘插入目标电脑的 USB 接口
2. 开机时按启动菜单快捷键（F12/F11/Esc 等）
3. 选择 U 盘启动
4. 在 Ventoy 菜单中选择需要的 ISO（WinPEEnhanced 或 FirPE）
5. 进入 PE 桌面环境

### 无硬盘场景下可进行的操作

| 操作 | 说明 |
|------|------|
| 装新硬盘后装系统 | 装上新 SSD/HDD，在 PE 里用分区工具分区，然后运行 Windows 安装程序 |
| 网络安装 | PE 里有网络支持，可以映射网络驱动器获取镜像文件 |
| 数据恢复 | 如果旧硬盘有问题，可用 PE 里的 DiskGenius 等工具恢复数据 |
| 硬盘检测 | 用 CrystalDiskInfo 检测硬盘健康状况和 SMART 信息 |

> **注意：** PE 运行在内存中，重启后 PE 环境里的数据会丢失。需要保存的文件请存到 U 盘或网络存储上。

## 第三部分：笔记本花屏黑屏故障排查

### 故障现象

> **症状描述：** 笔记本开机后出现蓝色花屏，随后变黑屏，开机键闪烁。无蓝屏错误代码。故障概率性发生，有时能正常启动，有时花屏后自动恢复。

### 症状分析

这一系列症状的组合 — **花屏 → 黑屏 → 开机键闪烁 → 概率恢复** — 指向以下几个关键判断：

- **花屏**不是普通蓝屏，是显示信号异常，通常与显卡、显存、屏线相关
- **开机键闪烁**表示笔记本经历了异常关机/保护重启
- **刚开机就花屏**排除了过热因素，指向硬件接触不良
- **概率发生**符合虚焊或接触不良的特征（冷机易犯，热机恢复）

### 可能原因与概率

| 概率 | 原因 | 特征 | 维修费用预估 |
|------|------|------|-------------|
| 35% | 显卡虚焊 | 冷机时焊点收缩接触不良，热机后膨胀恢复 | 200-400 元（重焊 GPU） |
| 25% | 屏线松动/老化 | 拍打屏幕边缘花屏会变化 | 100-200 元 |
| 20% | 过热保护 | GPU/CPU 过热触发断电保护 | 50-100 元（清灰换硅脂） |
| 15% | 主板供电不稳 | 电容老化导致供电异常 | 300-500+ 元 |
| 5% | 屏幕面板老化 | 屏幕即将彻底损坏 | 300-600 元 |

### 排查步骤（从易到难）

#### 第一步：外接显示器测试（关键）

找一台显示器或电视，用 HDMI/Type-C 线连上笔记本：

| 外接结果 | 判断 |
|---------|------|
| 外接显示器正常 | 屏线或屏幕问题（维修较便宜） |
| 外接也花屏/黑屏 | 显卡或主板问题（维修较贵） |

#### 第二步：外接键盘测试

花屏黑屏后，按 `Caps Lock` 或 `Num Lock` 键：

- **指示灯能亮灭** → 系统还在运行，只是显示出问题
- **指示灯无反应** → 整机死机/崩溃

#### 第三步：用 PE 盘启动测试

用做好的 PE 盘启动笔记本，观察 PE 环境下是否也花屏：

- **PE 里正常** → 问题在 Windows 驱动或系统层面，重装驱动或系统
- **PE 里也花屏** → 硬件问题（显卡/内存/主板）

#### 第四步：重插内存条

笔记本拆开后盖 → 取出内存条 → 用橡皮擦金手指 → 装回去。这是零成本操作，有时能解决接触不良引起的花屏。

#### 第五步：检查温度

如果有时能正常开机，在 Windows 中下载 HWMonitor 监控温度：

- 正常温度应低于 85°C
- 超过 95°C 属于危险，需要清灰换硅脂
- 如果刚开机温度就很高，说明散热系统有问题

### 利用 PE 盘进行硬件检测

在 PE 环境（推荐 FirPE）中可使用的检测工具：

| 检测项 | 工具 | 操作 |
|--------|------|------|
| CPU/主板/内存信息 | CPU-Z | 查看硬件详细规格 |
| 硬盘健康 | CrystalDiskInfo | 读取 SMART 信息，检测坏道 |
| 硬盘分区/数据恢复 | DiskGenius | 分区管理、数据恢复 |
| 温度/电压监控 | HWMonitor | 实时监控各传感器 |
| 内存检测 | Windows 内存诊断 | 检测内存条故障 |

## 第四部分：总结与建议

### PE 盘的价值

一个制作好的 PE 盘是电脑维护的**万能工具箱**，可以用于：系统安装、数据恢复、硬件检测、分区管理、密码重置等场景。Ventoy 方案的优势在于可以随时增删 ISO，一个 U 盘容纳多个维护工具。

### 笔记本花屏的应对策略

| 策略 | 说明 |
|------|------|
| 立即备份 | 趁电脑正常时备份重要数据到 U 盘或云盘 |
| 记录故障日志 | 打开事件查看器查看 Kernel-Power 和 Display 错误，截图保存 |
| 先试零成本方案 | 重插内存条、外接显示器测试、PE 盘启动测试 |
| 清灰换硅脂 | 如果是旧笔记本（3 年以上），优先清灰换硅脂 |
| 频繁发生则送修 | 如果花屏越来越频繁，很可能是显卡虚焊，需送维修店重焊 |
| 拍照记录 | 花屏时立刻拍照，记录是否在高负载时发生，供维修人员参考 |

> **核心建议：** 对于"刚开机就花屏、概率发生、然后恢复"的症状组合，最符合**显卡虚焊**的特征。冷机时焊点收缩导致接触不良，热机后膨胀恢复。如果故障频率逐渐升高，建议尽早送维修店重焊 GPU，避免彻底损坏后维修成本更高。
